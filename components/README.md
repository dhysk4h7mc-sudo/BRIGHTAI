# BRIGHTAI — Component Library

> مكتبة مكونات HTML جاهزة للاستخدام لمنصة BRIGHTAI

## الملفات

| الملف | المكون | الوصف |
|---|---|---|
| `button-primary.html` | زر أساسي | CTA ذهبي مع ظل توهجي |
| `button-secondary.html` | زر ثانوي | زر bordered بالـ Cyan |
| `button-ghost.html` | زر شفاف | زر خفيف بدون خلفية |
| `card-glass.html` | بطاقة زجاجية | Glassmorphism card مع backdrop-filter |
| `card-feature.html` | بطاقة مميزة | Feature card مع شارة وإحصائيات |
| `card-kpi.html` | بطاقة مؤشر | KPI metric card مع تغييرات |
| `form-input.html` | حقل إدخال | Text, email, select, textarea مع حالات |
| `form-search.html` | بحث | شريط بحث موسع + بحث التنقل |
| `modal.html` | نافذة منبثقة | Modal مع backdrop وتأثيرات |
| `table.html` | جدول بيانات | Data table مع pagination وحالات |
| `nav-unified.html` | تنقل موحّد | Glassmorphism navbar مع dropdowns |
| `breadcrumb.html` | مسار تنقل | Breadcrumb RTL |
| `badge.html` | شارات | Badges بأنواع متعددة |
| `toast.html` | إشعارات | Toast notifications بأنواع مختلفة |
| `chat-widget.html` | ويدجت المحادثة | Floating chat مع FAB |

## الاستخدام

كل ملف HTML مكون مستقل يحتوي على:
- ✅ `dir="rtl"` و `lang="ar-SA"`
- ✅ ربط بـ `design-system.css` للمتغيرات
- ✅ ربط بـ `asset-fonts.css` للخطوط
- ✅ Iconify للأيقونات

افتح أي ملف مباشرة في المتصفح لمعاينة المكون.
