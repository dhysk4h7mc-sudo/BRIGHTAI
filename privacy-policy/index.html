1. مقدمة

توضح هذه السياسة كيف تتعامل BrightAI مع البيانات التي قد تُقدّم لنا عبر الموقع الإلكتروني، نماذج التواصل، طلبات الديمو، المحادثات التجارية، أو عند استخدام الخدمات التجريبية والمنصات التي نقدمها للعملاء.

نستخدم عبارات حذرة ومحددة لأن معالجة البيانات تختلف حسب طبيعة الخدمة، نطاق المشروع، والاتفاقيات الموقعة مع العميل.

2. نطاق السياسة

تغطي هذه السياسة الموقع الإلكتروني، نماذج التواصل، طلبات الديمو، المحادثات التجارية، الخدمات التجريبية، والأنظمة أو المنصات التي تقدمها BrightAI للعملاء متى كانت BrightAI مسؤولة عن تشغيلها أو دعمها وفق الاتفاق.

3. البيانات التي قد نجمعها

  • بيانات الهوية والتواصل: الاسم، البريد الإلكتروني، رقم الجوال، الشركة، والمسمى الوظيفي.
  • بيانات الاستخدام: الصفحات التي تمت زيارتها، نوع الجهاز، المتصفح، وعنوان IP لأغراض تقنية وتحليلية.
  • بيانات التواصل: الرسائل، طلبات الدعم، الاستفسارات، وملاحظات الاجتماعات التجارية.
  • بيانات الأعمال: نوع الشركة، القطاع، الاحتياج، أنظمة التكامل المطلوبة، ونطاق الحل المقترح.
  • ملفات أو مستندات: أي ملفات يرسلها العميل طوعاً لغرض التقييم أو إعداد العرض أو تنفيذ الخدمة.

4. كيف نستخدم البيانات

نستخدم البيانات للرد على الاستفسارات، ترتيب الديمو، تقديم الخدمات، تحسين الموقع وتجربة المستخدم، التواصل التجاري، إعداد العروض أو المقترحات، والوفاء بالمتطلبات النظامية والتعاقدية عند وجود علاقة عمل أو اتفاقية موقعة.

5. الذكاء الاصطناعي والبيانات

قد تستخدم BrightAI تقنيات ذكاء اصطناعي لمعالجة الطلبات، تحليل الاحتياجات، أو تشغيل أنظمة الحوكمة والأمان. لا نستخدم بيانات العميل الحساسة لتدريب نماذج عامة إلا بموافقة صريحة ومكتوبة.

يتم التعامل مع بيانات العملاء وفق ضوابط السرية والتعاقد. وفي بيئات العملاء، يمكن تطبيق سياسات إخفاء PII، سجلات تدقيق، وضوابط وصول حسب نطاق المشروع.

تنبيه مهم

BrightAI يساعد العملاء على تحسين جاهزية الامتثال وتطبيق ضوابط حماية مناسبة، ولا يدعي توافقاً قانونياً مطلقاً خارج نطاق الاتفاقيات والمراجعات المتخصصة.

6. مشاركة البيانات

لا نبيع البيانات الشخصية. قد نشارك الحد الأدنى اللازم مع مزودي الاستضافة، أدوات التحليلات، أنظمة البريد والتواصل، أو مزودي خدمات ضروريين لتشغيل الموقع أو الخدمة، مع مراعاة السرية وتقليل البيانات قدر الإمكان.

7. الاحتفاظ بالبيانات

نحتفظ بالبيانات للمدة اللازمة لأغراض التواصل، تقديم الخدمة، إدارة العلاقة التجارية، أو الالتزام النظامي والتعاقدي. بعد انتهاء الحاجة، يتم حذف البيانات أو أرشفتها بشكل آمن حسب طبيعة البيانات والمتطلبات ذات العلاقة.

8. حماية البيانات

  • ضوابط وصول وصلاحيات محددة.
  • تشفير عند الإمكان وحسب بيئة التشغيل.
  • مراقبة أمنية وتقليل للبيانات المتداولة.
  • مراجعة الصلاحيات وسجلات تدقيق عند الحاجة.

9. حقوق المستخدم

يمكن للمستخدم أو ممثل العميل طلب الوصول للبيانات، التصحيح، الحذف عند الإمكان، الاعتراض على بعض المعالجات، أو سحب الموافقة عندما تكون المعالجة مبنية على موافقة. قد نحتاج للتحقق من الهوية والصلاحية قبل تنفيذ الطلب.

10. الكوكيز

قد يستخدم الموقع ملفات كوكيز وتقنيات مشابهة لأغراض التحليلات، تحسين التجربة، وقياس أداء الصفحات. للمزيد راجع سياسة ملفات الارتباط.

11. نقل البيانات خارج المملكة

قد تتم معالجة بعض البيانات عبر مزودي خدمات سحابية أو أدوات تشغيل خارج المملكة بحسب طبيعة الخدمة، مع اتخاذ إجراءات مناسبة للسرية والحماية، ووفق المتطلبات النظامية والتعاقدية ذات العلاقة.

12. بيانات الأطفال

خدمات BrightAI موجهة للشركات والجهات، وليست موجهة للأطفال. لا نستهدف جمع بيانات الأطفال عبر الموقع أو الخدمات التجارية.

13. التحديثات على السياسة

قد يتم تحديث هذه السياسة من وقت لآخر لتعكس تغييرات تشغيلية أو نظامية أو تعاقدية. يظهر تاريخ آخر تحديث أعلى هذه الصفحة.

14. التواصل

لأي سؤال عن الخصوصية أو طلب متعلق بالبيانات، تواصل معنا عبر صفحة التواصل أو واتساب، أو عبر البريد: privacy@brightai.site.
